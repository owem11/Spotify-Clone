# Spotify Web Player Clone

A responsive, pixel-perfect frontend clone of the Spotify Web Player built with semantic HTML5, modern CSS (Flexbox & Grid), and vanilla JavaScript.

## 🚀 Features

* **Sticky Navigation Header:** Incorporates a search bar, navigation links, and a translucent glassmorphism blur effect on scroll.
* **Responsive Card Grids:** Powered by CSS Grid (`auto-fill`, `minmax`) to auto-fit playlist and genre cards across mobile, tablet, and desktop viewports.
* **Interactive Album Cards:** Micro-interactions including card lighting on hover, text truncation, and smooth sliding green play buttons.
* **Playlist Detail View:** Banner header layout with album artwork, metadata, and an accessible tracklist table.
* **Browse Section:** Distinctly styled genre cards featuring rotated decorative artwork.
* **Fixed Bottom Audio Player:** Media bar pinned to the viewport bottom containing playback controls, volume controls, and progress bars.
* **Accessibility First:** Integrated ARIA roles, semantic HTML tags, keyboard navigation support, and custom focus states.
* **Vanilla JavaScript Logic:** Interactive context dropdown menus with event listeners handling outside-click closing.
